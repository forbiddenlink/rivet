## 🚧 Known Issues & Limitations

### Current Limitations
1. **CLI Not Production Ready** - Basic structure exists but missing AI integration
2. **Flow Engine Incomplete** - Structure created but detection logic pending
3. **No Configuration System** - Cannot customize rules/thresholds yet
4. **Single Output Format** - Only console output, JSON/SARIF/HTML pending
5. **Manual Testing Only** - No automated E2E tests yet

### Technical Debt
1. **Error Handling** - Need more robust error messages
2. **Logging** - No debug mode or verbose logging
3. **Performance** - No benchmarking data yet
4. **Memory Usage** - Not tested with large codebases (>10k files)
