**Rivet your codebase with professional-grade code quality analysis**

RIVET is a comprehensive code quality and security platform that not only detects issues but explains WHY they matter and HOW to fix them. Unlike traditional linters, RIVET combines multiple analysis engines with AI-powered explanations to help developers write better, safer, more maintainable code.

> 🎯 **Phase 1 MVP Progress** - 8 engines operational, AI enhancement complete. [See Roadmap →](./docs/ROADMAP.md)

## ✨ AI-Powered Code Quality

```bash
$ rivet scan --ai

💡 **Cyclomatic Complexity in processPayment (line 42)**
   Explanation: This function has 7 nested conditionals, making it hard to test and maintain.
   
🔧 Suggestion: Extract payment validation into a separate validatePayment() method,
   then use early returns to reduce nesting depth.
   
📖 Analogy: Like a recipe with too many "if the oven is hot, then if you have flour..."
   steps - break it into separate prep tasks instead.
   
⏱️  Tech Debt: 2 hours to refactor

$ rivet scan --tech-debt
Total Technical Debt: 18.5 hours (2.3 days)
└─ By Category:
   ├─ Security: 8.0 hours (43%)
   ├─ Performance: 4.5 hours (24%)  
   ├─ Maintainability: 6.0 hours (32%)
```

## 📋 Features Overview

### Analysis Engines

1. **Code Smell Detector** - 15+ patterns (long methods, god objects, duplicate code, etc.)
2. **Bug & Error Detector** - Null references, logic errors, memory leaks, race conditions
3. **Security Scanner** - OWASP Top 10, SQL injection, XSS, exposed secrets, vulnerabilities
4. **Performance Analyzer** - Algorithmic complexity, bundle size, unnecessary re-renders
5. **Architecture Analyzer** - SOLID violations, circular dependencies, tight coupling
6. **Best Practices Advisor** - Modern patterns, framework-specific improvements
7. **Dependency Manager** - Outdated packages, vulnerabilities, unused dependencies
8. **Flow Testing Engine** - Critical path detection, untested user journeys

### Smart Features

- **AI Explanations** - Context-aware explanations with analogies
- **Auto-Refactoring** - Modernize code automatically (callbacks → async/await)
- **Breaking Change Analysis** - AI reads changelogs before updating
- **Dead Code Elimination** - Remove unused files, exports, dependencies
- **Bundle Optimization** - Import analysis, code splitting suggestions
- **License Compliance** - Detect incompatible licenses
- **Tech Debt Scoring** - 0-100 score with actionable roadmap

## 💻 CLI Commands

```bash
# Scanning
rivet scan                      # Full scan (all engines)
rivet scan --only security      # Specific category
rivet scan --watch             # Continuous monitoring

# Fixing
rivet fix                      # Interactive fix mode
rivet fix --safe              # Auto-fix safe issues
rivet fix security            # Fix only security issues

# Dependencies
rivet deps check              # Check for updates & vulnerabilities
rivet deps update             # Interactive update
rivet deps clean              # Remove unused dependencies
rivet deps licenses           # License compliance report

# Flow Testing
rivet flows scan              # Detect all user flows
rivet flows coverage          # Flow test coverage
rivet flows generate          # Generate test skeletons
rivet flows critical          # Show untested critical paths

# Refactoring
rivet refactor                # AI-suggested refactorings
rivet modernize               # Update to modern syntax
rivet migrate react18         # Framework migrations

# Analysis
rivet score                   # Tech debt score
rivet bundle                  # Bundle size analysis
rivet coverage                # Test coverage gaps

# Reporting
rivet report                  # HTML dashboard
rivet report --json           # CI/CD friendly
rivet report --security       # Security-focused report

# CI/CD
rivet ci                      # CI mode (fail on critical)
rivet ci --baseline           # Save baseline
rivet ci --compare            # Compare against baseline
```

## 🏗️ Architecture

RIVET uses a modular architecture with multiple analysis engines running in parallel:

```
Source Code
    ↓
Parser Layer (AST + Type Info)
    ↓
Parallel Analysis Engines
    ↓
AI Explanation Generator
    ↓
Auto-Fix Engine
    ↓
Output (CLI / Web / IDE)
```

See [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) for detailed information.

## 🛠️ Tech Stack

- **Language**: TypeScript (100%)
- **Runtime**: Node.js 20+
- **Monorepo**: Turborepo + pnpm
- **Parsing**: @typescript-eslint, tree-sitter
- **Security**: Semgrep, eslint-plugin-security
- **Dead Code**: Knip
- **Refactoring**: jscodeshift
- **AI**: LangChain + OpenAI/Claude
