What each engine looks for

Engines run in parallel on the parsed syntax tree. Each finding carries a rule id, a severity, and the exact line and column.

EngineLooks forExample rules
SecurityInjection, hardcoded secrets, unsafe HTML, weak crypto and randomness, path traversalsql-injection hardcoded-secret xss-react
BugsLoose equality, constant or duplicate conditions, empty catches, unawaited promisesloose-equality empty-catch
PerformanceNested and blocking loops, DOM queries in loops, re-render waste in Reactnested-loops state-update-in-render
ArchitectureCircular dependencies, layer violations, high coupling, SOLID breakscircular-dependency layer-violation
Code smellsLong methods, god objects, deep nesting, duplication, magic numbersdeep-nesting god-object
PracticesLeftover console and debugger statements, thrown strings, naming, missing docsdebugger-statement throw-string
DependenciesUnused code, duplicate and side-effect imports, barrel-file chainsunused-code duplicate-imports
FlowsAsync paths without error handling, untested routes and reducers, missing error boundariesuntested-route missing-error-boundary

Explanations. Every finding comes with guidance. When the server has an OpenAI key, that guidance is written by a model and labeled as AI. Without one, you get RIVET's built-in guide for the category, labeled as such.

Use it where you already work

Local-first. Your code stays on your machine unless you opt into AI enhancement.

Terminal

Scan a whole project, add explanations and tech-debt hours.

$ pnpm --filter @rivet/cli dev \
    scan . --ai --tech-debt

Dashboard

Paste or upload one file and triage findings line by line in the browser.

Open the dashboard

CI

Emit SARIF for GitHub code scanning, or JSON and HTML reports.

$ pnpm --filter @rivet/cli dev \
    scan . --format sarif

Run it locally

Three steps from a fresh clone. Requires Node 20 or later and pnpm.

  1. 1
    git clone https://github.com/forbiddenlink/rivet && cd rivet
  2. 2
    pnpm install && pnpm build
  3. 3
    pnpm --filter @rivet/cli dev scan /path/to/projectAdd --ai with OPENAI_API_KEY set for model-written explanations.
